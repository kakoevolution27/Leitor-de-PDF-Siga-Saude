Um programa para automatizar a leitura de PDF-Agenda e PDF-Comprovante emitidos pelo SIGA-SAUDE. 

Este codigo em constante evolução visa facilitar o fluxo de trabalho com agendas no principal sistema usado pela saude publica (SUS) o SIGA SAUDE do qual não dispõe função para exportação do PDF nos formatos (EXCEL, CSV, etc)

Extrai dados gerados no PDF usando a biblioteca python PDFPLUMBER e Pandas que são a base para a automação.
